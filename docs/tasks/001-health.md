# Task 001 · 用 Go 启动健康检查接口

目标：在本机 18001 端口启动 HTTP 服务，访问 `GET /api/v1/health` 返回 JSON。先理解请求、响应和 JSON，不要求自动接口文档。

## 第一步：检查家中环境

在终端运行 `git --version` 和 `go version`，把输出交给导师；如果提示找不到命令，先停下，由导师指导安装。暂不运行未知的安装脚本。

## 接口契约

`GET /api/v1/health` 返回 HTTP 200 和 JSON：`ok` 为 true，`version` 为 `0.1.0`，`uptime` 为启动以来的秒数（数字，保留两位小数），`go` 为实际 Go 运行时版本，`home` 为环境变量 `TXLC_CONSOLE_HOME` 的值（未设置时为 null）。不读取配置、不写磁盘、不执行外部命令。

## 验收

由导师和用户在实现后按实际入口确定启动命令，并执行：请求接口，检查上述字段与 `Content-Type`；间隔两秒再次请求，uptime 应增长；POST 同一路径返回 405；未知路径返回 404；执行 `go test ./...`，并检查格式。服务只监听 127.0.0.1:18001。

## 学习点和提示

HTTP 是浏览器与服务交换请求和响应的约定；JSON 是传递数据的文本格式。Go 的 `net/http` 可以接收请求，`encoding/json` 可以编码响应，`time` 可用于计算运行时间。先从检查环境开始，后续由导师按步骤讲解；伪代码在用户主动要求时再提供。
