# 本地服务控制台 · 项目计划

> 2026-11-17：项目所有者决定后端改用 Go。本文为现行计划；由所有者编写代码，AI 担任需求方、评审和导师。

## 目标与边界

在 macOS 上用浏览器管理本地多个项目和服务：启停、构建、状态、日志、端口与 Git 操作。旧 dev-tools 保持运行，开发服务默认 18001，旧服务 18000。GitHub 私有仓库：`CherrySUKURA/txlc-console`。

不做 Git commit/push 代操作、远程多用户、容器编排或代码编辑器。打包自带控制台 Go 可执行文件；被管理项目仍需自行安装 Java、Maven、Node 等工具。

## 技术栈

- 后端：Go；先使用标准库 `net/http` 和 `encoding/json`，具体 Go 版本以家中环境和项目初始化时确定。
- 前端：Vue 3、TypeScript、Vite、Ant Design Vue 4；pnpm 管理依赖。
- 数据：TOML 文件，按项目 → 服务组织，数据路径由 `TXLC_CONSOLE_HOME` 指定。
- 测试：Go 标准库 testing；前端后续使用 Vitest。格式检查使用 gofmt。
- 接口：HTTP/JSON，前缀 `/api/v1`；第一版手写接口契约，接口增多后再评估 OpenAPI 类型生成。
- 打包：Go 可执行文件和前端静态资源封装为 macOS `.app` / `.dmg`；具体打包方式在 M4 验证。

## 功能与里程碑

### M0 地基

001 健康检查；002 TOML 配置加载与项目列表；003 新增项目与校验；004 Maven/Node 目录探测；005 单服务启停；006 状态与端口；007 增量日志；008 长任务骨架。

基础规则：服务状态明确，重复启动不产生多个进程；控制台重启后不能仅凭旧 PID 停止进程；配置校验与安全写入；敏感接口防止来自其他网站的未授权请求；日志清空或替换后恢复读取。进程树停止行为、配置恢复和安全策略需在相应任务卡中给出可执行验收。

## 协作和完成标准

一次只推进一张任务卡。所有者实现代码；AI 先解释概念和方向，只有主动要求时给伪代码或答案。完成后实际运行任务卡验收，评审分为必须改、建议改、可以忽略。每张卡完成后更新 STATE.md，遵守用户提供的 Git 提交流程和中文 Conventional Commits。
